# 0.6B Phrase Blind Evaluation v1

## 结论

**未通过。** `正确 + 基本可用 = 46%`，低于 `90%` 通过线；`明显错误 = 28%`，高于 `5%` 上限。Qwen3-0.6B 不适合作为 Phrase 的可信首选，当前“DeepSeek 优先、本地基础解析并提示核对”的方案 A 应继续保留。

## 约束

- 固定 50 条此前不在仓库 Prompt、safety set 或已有测试样例中的表达。
- 参考释义只保存在评测集，模型请求仅包含现有系统 Prompt 和当前 Phrase。
- 评测过程中没有修改 Prompt、模型、采样参数或 safety set。

## 发布决策

1. Word 继续使用本地 0.6B。
2. Phrase 在自动模式下继续 DeepSeek 优先。
3. DeepSeek 不可用时允许本地 0.6B 给出候选，但必须保留“本地基础解析 · 建议核对”标记。
4. 不把本轮失败表达加入 safety set，也不依据本轮结果修改 Prompt。
5. 若未来评估 1.7B，必须复用同一数据集、采样参数和评分规则。
